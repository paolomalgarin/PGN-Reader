# Brilliant animation concepts

L'animazione attualmente integrata è **05 — Hybrid Path + Badge**: unisce il percorso a caselle/corridoio luminoso del concept Luminous Lane con il badge semplice `!! BRILLIANT` del concept Glow Path.

Sequenza dell'effetto integrato:

1. la scacchiera si oscura;
2. le caselle del percorso si illuminano in verde smeraldo;
3. il pezzo viene riprodotto con l'animazione nativa di cm-chessboard e le caselle si spengono progressivamente dietro al movimento;
4. la scacchiera dà un breve feedback di tremolio;
5. appare il badge `!! BRILLIANT`, poi scompare;
6. l'oscuramento svanisce, mentre il NAG `!!` rimane come annotazione sulla mossa.

`Brilliant-05-Hybrid-Path-Badge.gif` è il concept visivo di riferimento. Le GIF 01–04 sono conservate come proposte alternative.
